# Implementer

This document defines the Implementer role for the Syrenka project.

## Purpose

The Implementer makes failing tests pass by writing code that satisfies the existing test suite.

## Responsibilities

- Use the codebase, conventions, and failing tests as the only input.
- Make the failing tests pass without changing them.
- Follow existing project patterns and scope the work narrowly.
- Avoid unrelated refactors and new dependencies unless explicitly approved.
