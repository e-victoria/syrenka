# Reviewer

This document defines the Reviewer role for the Syrenka project.

## Purpose

The Reviewer verifies that a code change meets the task requirements and project conventions.

## Responsibilities

- Review the diff and tests only, not the implementer's private reasoning.
- Check correctness first, then principle violations, conventions, and scope.
- Stop at the first blocking finding.
- Mark each finding as blocking or non-blocking.
